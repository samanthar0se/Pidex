Often confusedUse this distinction
Session vs turnA Session is the durable conversation scope; a turn is one presented prompt/work/response grouping.
Run state vs turn phaseRun state is Host-authoritative execution state; phase is a Client-derived presentation description.
Timeline entry vs activity rowThe entry is an authoritative fact; the row is its visual presentation inside a disclosure.
Interaction vs tool approvalAn Interaction is an exact Host request with identity/revision; it is not a generic tool confirmation.
Streaming vs workingWorking makes activity primary before an answer; streaming means an existing response entry is revising in place.
04 · Four ways to review

Separate concerns before giving feedback

The same visual element can be correct anatomically but wrong in authority, motion, or accessibility. Name the review lens explicitly.

Anatomy

Composition and hierarchy

Ask whether the interface tells the story prompt → work → response with the right visual priority.

1Is this the correct surface?
2Is it grouped at the correct level?
3Is ordinary detail progressively disclosed?
4Does the final answer own narrative width?
Authority

Identity and source of truth

Ask whether presentation preserves Host facts rather than inventing state, order, duration, or targeting.

1Which exact entry or Run owns this?
2Is the state authoritative or derived?
3Could stale state retarget an action?
4Was any semantic status inferred from prose?
Motion

Continuity and choreography

Ask whether state changes preserve identity, reading position, focus, and geometry while shifting visual priority.

1What enters once versus revises in place?
2Was the reader following or detached?
3Does disclosure motion move its trigger?
4Does reduced motion reach the same state?
Accessibility

Semantics and operation

Ask whether state is perceivable and operable by keyboard, touch, and assistive technology without noisy announcements.

1Is the control a real button?
2Do expanded/busy states stay truthful?
3Can hidden content receive focus?
4Does automatic change steal focus?
